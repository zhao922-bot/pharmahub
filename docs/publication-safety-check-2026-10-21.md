# GitHub 公开前信息泄漏检查

检查日期：2026-10-21。仓库：[zhao922-bot/pharmahub](https://github.com/zhao922-bot/pharmahub)。

## 范围与方法

- 从 GitHub 拉取独立镜像，检查 `main`、`online` 两个分支的全部可达提交历史，而不只检查最新文件；检查时没有标签或其他分支。
- 使用 [Gitleaks v8.30.1](https://github.com/gitleaks/gitleaks/releases/tag/v8.30.1) 默认规则扫描历史，忽略代码中的跳过扫描注释，启用完全脱敏输出。扫描工具来自官方发布，下载文件已按官方校验和核对 SHA-256。
- 补充检查全部历史文件对象、提交者身份和敏感文件名，覆盖个人目录路径、邮箱、手机号特征、带凭据的 URL、私钥、数据库文件、导出文件、日志与压缩包。
- 人工复核命中的邮箱、测试数据、数据库迁移、托管配置和验收文档，并检查 GitHub 发布附件、Issue/PR、Actions 日志及构建产物。

## 检查结果

- 密钥扫描未报告泄漏；未发现已提交的 API 密钥、访问令牌、私钥、密码配置或带凭据的连接 URL。
- 未发现真实个人学习数据库、学习记录导出、用户会话或运行日志。迁移文件仅包含表结构，测试中的学习记录为模拟账号生成的数据。
- 未发现个人电脑用户目录路径或个人手机号。提交身份使用 GitHub 的 `users.noreply.github.com` 隐私邮箱；开发模拟邮箱与依赖包公开维护邮箱不是真实学习用户资料。
- 历史中的二进制文件为站点图标。数据库、环境变量、运行时状态和本地导出等不在此次公开的源码中。
- 检查时没有 Releases/附件、Issue/PR、Actions 运行或构建产物，Wiki 与 Discussions 未启用。
- `.openai/hosting.json` 保留部署所需的站点项目 ID 和逻辑数据库绑定名；这些是资源标识，不是数据库密码或访问令牌。

## 公开范围与维护边界

公开仓库包含应用源码、药物学习内容、测试和文档。公开源码不公开 Cloudflare D1 中的个人学习数据，也不取消线上应用的登录与账号隔离。

此记录是发布前信息泄漏检查，不是完整软件安全审计或医学专业复审；扫描不能证明不存在任何形式的敏感信息。后续提交仍应避免加入凭据、真实用户数据、导出文件与运行日志。不得将自动测试或本检查结果表述为绝对安全保证。
